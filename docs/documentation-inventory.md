Clasificación primaria: **canónico** (contrato/decisión), **operativo** (continuidad/procedimiento), **propuesta** (mecanismo aún no aprobado en bloque), **histórico** (evidencia por corte) o **redundante** (redirección sin contrato propio). Un documento puede contener secciones de varias clases; se explicita en propósito/recomendación. «Parcialmente obsoleto» no invalida su contrato completo: identifica encabezados de estado, recomendaciones o propuestas superadas. «Histórico» no significa eliminable; «vigente» no significa implementado o desplegado.

Autoridad por tema: decisiones/reglas → contratos específicos → código para implementación; checkpoint para continuidad y roadmap para prioridades. Un encabezado antiguo «Draft/no integrado» no prevalece sobre el corte verificado del checkpoint. La historia no autoriza operaciones nuevas. No se modifica ningún ADR ni contrato clínico aprobado en esta auditoría.
